# シンプルタイマー

ブラウザだけで動くカウントダウンタイマー。ビルド不要・依存パッケージなしの静的サイトです。

## 使い方

`index.html` をブラウザで開くだけで動きます。ローカルサーバー経由でもOK：

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 機能

- プリセット（1 / 3 / 5 / 10 / 25分）とカスタム入力（分・秒）
- スタート / 一時停止 / リセット
- 残り時間を示す円形プログレスと、タブタイトルへの残り時間表示
- 終了時にビープ音（Web Audio APIで生成、音声ファイル不要）
- キーボード操作: `Space` でスタート・一時停止、`R` でリセット
- ライト / ダークモード自動対応

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | マークアップ |
| `style.css` | スタイル（CSS変数でテーマ切り替え） |
| `script.js` | タイマーのロジック |
